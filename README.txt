Mobile Auto Works website refresh

The redesign keeps the existing page content, Salem-area service description, phone number, Facebook link, email, and MAW monogram. It changes the visual palette to charcoal, white, and restrained red, with clearer hierarchy, responsive service cards, and more direct contact actions.

To publish, replace these three files in the root of the existing mobile-autoworks-site repository and commit them to the branch used by GitHub Pages.
