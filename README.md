## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new repository named `mobile-auto-works-site`.
2. Make the repository **Public** for the simplest free GitHub Pages setup.
3. Upload `index.html`, `styles.css`, and `favicon.svg` to the repository's top level (root).
4. Open repository **Settings** and select **Pages**.
5. Under build/deployment, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait a few minutes. GitHub will display the published website URL in Pages settings.
8. Open the URL on your phone and test the call, email, Facebook, and navigation links.

## Notes
This is a static website and intentionally has no contact form. Phone and email links open the visitor's phone/mail app. Hosting on GitHub Pages can be free for public repositories; a custom domain is optional and usually has an annual registration cost.
